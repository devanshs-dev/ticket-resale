# 🎫 TicketResale

A full-stack ticket resale marketplace with ML fraud detection, real-time availability, and QR-based ticket verification.

**Live Demo:** https://ticket-resale-phi.vercel.app

## Tech Stack
- Frontend: React + Tailwind CSS (Vercel)
- Backend: Node.js + Express + JWT (Render)
- ML Service: Python + Flask + Scikit-learn (Render)
- Databases: MongoDB Atlas + PostgreSQL
- Real-time: Socket.io

## Features
- JWT Authentication
- Ticket listings with search and category filter
- ML-based Trust Score (fraud detection)
- ML price suggestion
- QR code on purchase
- Real-time sold ticket updates
- Live viewer count
- Analytics dashboard (PostgreSQL)
- Admin panel
